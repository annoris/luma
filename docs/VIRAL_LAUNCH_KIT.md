I built an interactive zero-dependency web showcase (LUMA Botanical Soda) and wrote a compact procedural soundtrack engine (`assets/js/soundtrack.js`) using only the native Web Audio API.

**Live Demo:** [LIVE_DEMO_URL]
**Source Code (MIT):** [GITHUB_REPO_URL]

**How the audio scheduler works:**
- Uses a lookahead scheduling loop (`context.currentTime + 0.18`) driving a 128-step (8-bar) cycle at 106 BPM.
- Routes all voices through a master `GainNode` into a `DynamicsCompressorNode` (`threshold: -20`, `ratio: 3`) for a warm, cohesive mix.
- Generates deterministic percussion using a Park–Miller LCG (`16807 % 2147483647`) into an `AudioBuffer` filtered through a 6.5 kHz high-pass biquad filter for the shaker.
- Synthesizes low-pass filtered triangle chords, sine bass/motif voices, and an exponential pitch-drop sine kick — cleaning up and disconnecting every node via `onended`.

The rest of the site is also 100% dependency-free Vanilla JS, CSS3 (including a pure CSS soda can and 3-flavor state switcher), and HTML5. Happy to answer questions on the Web Audio timing or vanilla architecture!
